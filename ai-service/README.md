# AI Service

The AI layer of FitFlow leverages TensorFlow Lite for core on-device intelligence.

**Core Responsibilities & Capabilities:**
- Providing personalized workout recommendations based on user fitness data.
- Enabling fast, on-device machine learning inference.
- Reducing dependency on constant cloud connectivity and processing.
- Enhancing user privacy by processing sensitive fitness and health data locally on the device.
- Integrating with backend Cloud AI services for complex tasks that exceed on-device capabilities.
